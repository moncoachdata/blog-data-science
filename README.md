# Blog MonCoachData : notebooks et données

Notebooks Jupyter et jeux de données des tutoriels publiés sur
[moncoachdata.com](https://moncoachdata.com/blog/) : Python, Pandas, NumPy,
visualisation, SQL, Machine Learning et séries temporelles.

## Organisation

Un dossier par article. Le nom du dossier est la fin de l'URL de l'article
(`moncoachdata.com/blog/<nom-du-dossier>/`). Chaque dossier contient le notebook
`.ipynb` et, quand c'est nécessaire, les petits fichiers de données qu'il utilise.

Les jeux de données publics (Kaggle, UCI, OpenFlights, etc.) ne sont pas copiés
ici : les notebooks les téléchargent depuis leur source d'origine.

## Utiliser un notebook

1. Ouvre le dossier de l'article, puis le fichier `.ipynb`.
2. Clique sur « Open in Colab » ou utilise le lien Colab donné dans l'article.
3. Exécute les cellules dans l'ordre.
